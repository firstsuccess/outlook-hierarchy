# 作成画面のピン留め（v1.1.0.0）

## 利用者の操作

1. 公開サイトから最新のmanifest.xmlをダウンロードして登録を更新します。手動サイドロードで更新が反映されない場合は既存アドインを削除・再登録します。Excel共有URLを控えてから行ってください。
2. **メール作成画面**から組織アドレス帳を一度開きます。
3. Outlookが表示するパネル上部のピンアイコンを利用者が一度押します。アドイン内の設定ボタンとは別の、Outlook側の操作です。
4. 対応するOutlookでは次のメール作成時もパネルを維持できます。閲覧モードと作成モードのピン留めは別です。本製品は作成画面が対象です。

ピン留めはOutlookが管理します。アドインからピンを強制的に押したり、Outlookの完全終了後に必ず自動起動させたりする実装はありません。再起動後に表示されない場合はメール作成画面から開き直してください。保存したExcel参照はRoamingSettingsから読み込み直します。認証・取得済み社員データは永続保存しません。

## 実装

- Add-in IDを維持し、Versionを1.1.0.0に更新。
- VersionOverrides v1.0の中にv1.1を入れ、Mailbox 1.5対応クライアントの作成画面ShowTaskpaneアクションにSupportsPinning=trueを指定。
- v1.0 / Mailbox 1.3では従来の手動起動へフォールバック。
- Office.onReady内でItemChangedを監視し、現在のメールが作成モードか再判定。nullや閲覧モードでは宛先追加を無効化。
- メール切り替え時は選択社員と処理メッセージをリセットし、組織データ・検索条件・設定画面は維持。Excelを切り替えごとに取得し直すことはありません。
- 宛先取得中にメールが切り替わった場合は、宛先追加を中断。
- アドイン画面の再生成時にイベント購読を解除して重複を防止。

## 対応と確認範囲

Microsoft 365のWeb / New / 対応ビルドのClassic Outlookが対象です。Outlook.com・予定/会議は対象外です。自動テストではアイテム切り替え、null、イベント購読解除、旧ホスト、宛先追加中の切り替えを検証します。実機でのピンアイコン表示・次のメール・別ウィンドウ・Outlook/PC再起動後の復元は利用者環境で確認が必要です。
